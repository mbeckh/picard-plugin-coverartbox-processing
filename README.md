# Cover Art Box Processing

A plugin for [MusicBrainz Picard](https://picard.musicbrainz.org) to add cover art processing for files added through the UI.

## What it Does

The plugin patches the cover art box to perform cover art processing on files added using the covert art box in the meta data view.
This implements the behavior suggested in https://tickets.metabrainz.org/projects/PICARD/issues/PICARD-3547.
